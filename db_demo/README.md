# University Management System — application directory

This directory contains the academic web/API routes and React schema visualizer described in the [repository README](../README.md).

Use the parent README for verified features, database relationships, authentication scope, and installation instructions. Its setup commands enter this `db_demo/` directory before running Composer, Artisan, or npm.

Setup remains untested in a clean environment. The demo seeder truncates academic tables; use only a disposable local database. No production-readiness claim is made.
